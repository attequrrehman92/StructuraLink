# StructuraLink: SAP2000 Edition

StructuraLink is a desktop companion for **SAP2000**, made by structural engineers for structural engineers. It
covers results extraction and envelope summaries, load combinations by code, design checks and loading
calculators. It also includes a structural glass analyzer (ASTM E1300-24), a geodesic dome constructor and
buckling analysis, all pushed to and read from your SAP2000 model.

## Download

Get the latest installer from the **[Releases](../../releases/latest)** page. Download `StructuraLink_Setup_x.y.z.exe`
and run it. A new version installs over the old one.

Once installed, the app checks this page for you: open **Help → Check for Updates**.

## Requirements

- Windows 10 or 11 (64-bit)
- SAP2000 (v21 or later; v23 recommended) for the features that work with a model

## Support

Report a problem from inside the app with **Help → Report an Issue**. It goes straight to the developer, no login
needed.
